Project name is Thala ki ladki a Custom Emoji GIF Designer 

the Idea

Its An  web platform where users can:
 Pick a base emoji (from a set or upload their own).

 Customize it (colors, text, accessories like glasses, hats, etc.).

 Add animations (shake, bounce, dance, glow, rotate).

 Export it as a GIF or download/share.




 Features

Emoji Library

Provide a set of emojis to start from.

Option to upload custom PNG/JPG emojis.

Customization Tools

Change background color.

Add stickers (glasses, crown, heart, etc.).

Add text with fun fonts.

Animation Tools

Predefined animation styles: bounce, zoom, shake, spin.

Apply filters (neon glow, rainbow effect).

GIF Generator

Convert customized emoji into a looping GIF.

Download option (GIF/MP4).

One-click share (WhatsApp, Instagram, etc.).
